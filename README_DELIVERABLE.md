# 滚动快门 / 分段曝光 / 全局快门仿真

纯 Go（标准库）实现，无任何外部依赖。运行：

```
go run .
```

输出全部写入 `artifacts/`，图像为二进制 P6 PPM，可直接用常见看图工具打开。

## 物理模型

- 场景是一根世界坐标固定的垂直刚性杆，相机做一次平滑横向摇镜：
  `加速斜坡 -> 匀速平台 -> 减速到零`，首尾均为静止（`sim.go` 的 `panVel`/`panPos`，
  位置由速度解析式积分，静止段位置严格恒定，无数值漂移）。
- 每个传感器行在各自的曝光窗口内做时间超采样积分（默认 5 个时刻），
  因此快速摇镜时同时呈现真实的运动模糊，而不是冻结姿态。
- 杆边缘位置由解析式给出（`render.go` 的 `rodLeftEdge`），与像素渲染共用同一时间映射。

## 三条快门路径

- `rolling`：逐行曝光，行 `y` 的采样时刻随行号线性扫过整个读出时间 `ReadoutT`。
  摇镜时各行记录的姿态不同，刚性杆被渲染成弯曲/倾斜。
- `segmented`：分段曝光，每 `BlockRows` 行共享一个曝光时刻；段间用宽度
  `2*FeatherRows` 的线性羽化带过渡。时间映射连续且相邻行差值有界，
  因此分段边界不会出现跳行（见测试与报告中的 `borderStep`）。
- `global`：全局快门，所有行共享同一采样时刻，杆在任何帧都保持笔直。

## 产物

- `artifacts/<shutter>/frame_XX.ppm`：连续帧序列（每路径 20 帧）。
- `artifacts/<shutter>/edges.csv`：每帧逐行杆左边缘坐标矩阵（行 × 帧）。
- `artifacts/<shutter>/shear_heatmap.ppm`：剪切量热图，列为帧、行为传感器行，
  颜色为相对该帧均值的有符号偏差，三条路径共用同一蓝-白-红发散色标。
- `artifacts/edge_trajectory.ppm`：杆边缘轨迹，顶/中/底三行（红/琥珀/绿）
  随帧号的位置曲线，每路径一个面板，虚线为静止参考位；全局面板三条曲线重合，
  以白色粗线表示。
- `artifacts/report.txt`：量化统计（最大剪切、相邻行最大跳变、边界跳变、静止偏差）。

## 不变量与验证

`go test ./...` 覆盖：

- 静止相机下三条路径的杆在所有帧完全笔直；
- 摇镜结束恢复静止后，末帧所有行边缘一致（形状回正，仅整体平移）；
- 摇镜中滚动/分段路径显著弯曲而全局路径剪切恒为 0；
- 分段曝光相邻行边缘差有界、段边界无跳行，段内时刻恒定、羽化区连续；
- 摇镜结束后速度为 0 且位置不再漂移。
